# UjuziChain 5–10 Minute Demo Checklist

Suggested target: **7–8 minutes**.

- [ ] 0:00–0:30 — State the problem and the updated supervisor requirement.
- [ ] 0:30–1:10 — Show repository structure and tools.
- [ ] 1:10–1:50 — Show updated platform workflow diagram.
- [ ] 1:50–2:30 — Show key Solidity contract functions.
- [ ] 2:30–3:00 — Run `npx hardhat compile` and `npx hardhat test`.
- [ ] 3:00–3:30 — Show Hardhat local network and deployed contract address.
- [ ] 3:30–4:20 — Open the frontend dashboard and verified profile.
- [ ] 4:20–5:10 — Browse all jobs and explain that job discovery is not gated by match score.
- [ ] 5:10–5:50 — Select a low-match role and apply anyway.
- [ ] 5:50–6:40 — Run the role simulation and show the simulation score as extra application evidence.
- [ ] 6:40–7:10 — Show credential verification on the blockchain registry.
- [ ] 7:10–7:40 — Explain external job ingestion via approved APIs/feeds and the deployment plan.

## Key message

**Verification improves trust and matching; it does not prevent candidates from seeing or applying for opportunities. Simulations give candidates another way to demonstrate capability.**
